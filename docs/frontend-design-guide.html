1. Design Philosophy & Honesty Boundaries

ComPlix. pairs a calm, editorial aesthetic—soft off-white and sage surfaces, crisp 1px borders, and grounded forest-green primary actions—with strict architectural honesty. Users own their component libraries, choose frameworks independently per project, and collaborate in optional shared organization spaces.

Horizontal Page Navigation
Top-level and project views render as distinct URL-backed pages using soft horizontal pill buttons. Inactive pages are never kept hidden in the DOM.
Honest Draft & Mock Labels
Clearly distinguish Mock HTML Fixture and Unverified AI Draft states from validated components. Never imply compilation or promotion unless verified.
Built-in Operator AI Chat
End users never supply AI keys. Project chat uses operator backend configuration, while uploaded references (max 128 KiB) render as escaped plain text.

2. Dual-Theme Color Palette (Light & Dark Mode)

ComPlix supports both a warm Light Theme (matching the primary production workspace) and a low-glare Dark Theme built on deep forest-slate surfaces. All components reference semantic CSS variables so switching themes requires zero layout changes.
